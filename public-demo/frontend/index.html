Ce que fait cette page

La recherche interroge LinkedIn et Indeed via JobSpy, qui renvoie des résultats déjà structurés — titre, entreprise, lieu, date. Aucun texte n'est envoyé à un modèle de langage, aucune donnée personnelle n'est demandée.

Le score de compatibilité, la génération d'email de candidature et le chat local nécessitent un modèle de langage tournant sur votre machine — ils ne sont donc pas disponibles ici, mais fonctionnent dans la version complète.

# obtenir la version complète, en local
$ git clone https://github.com/AdemYehmed/local-job-agent.git
$ cd local-job-agent
# voir README.md pour la suite (LLM local, envoi d'email...)
